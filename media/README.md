# Media

Everything in this directory is supplied by the team. Each subdirectory has its
own README naming the exact files expected. Nothing here is generated by code.

| Directory | What goes here | Used by |
|---|---|---|
| `award/` | Award ceremony photographs | README hero strip, `docs/07-results-and-lessons.md` |
| `renders/` | 3D renders of the robot | README header |
| `robot/` | Real photographs of the robot | README, `hardware/README.md`, `hardware/docs/bom.md` |
| `video/` | YouTube link to the official competition video | README, `docs/07-results-and-lessons.md` |
| `runs/` | Figures drawn from the four match reports and the recorded pose log | `navigation/README.md`, `mission/README.md` — see `runs/README.md` |
| `perception/` | Scan overlays and the scan clip, off the robot | `README.md`, `perception/README.md` |
| `clips/` | Isaac Sim stage clips (generated — see `simulation/clips/`) | README, `navigation/README.md` |

Guidance for all images: max 2000 px on the long edge, JPEG for photos and PNG
for renders with transparency. Check that no non-team member's face is
identifiable before publishing.
