The standings chart is regenerated by `make_leaderboard.py` (no inputs — the
scores are in the script). The two photographic sheets were built from the
render sets and a real arena capture, neither of which ships here.

## The standings chart

Two SVGs, one per GitHub theme, selected with `<picture>` in the README rather
than flipped automatically — the dark variant uses its own steps from the same
palette, not inverted colours.

Series colours are categorical slots 1 and 2 of the reference data-viz palette,
checked with its validator against both surfaces: worst adjacent CVD ΔE 24.7
light / 26.8 dark, well above the 8 target. Rank is never encoded in colour —
hue means *which match*, and the winner is marked with a background band and
weight instead, so a filter or a re-sort could never repaint the series.
